Python project for basic control of Epic Beaker to allow smart template functionality. Contains GUI for modular script integration. Fork from original Auto Dictation program, tailored for use at NW-Delnor.

Run program, and utilize the user interface. The program requires that Epic Beaker be open and visible on the screen. The program works best with a two monitor setup, where Epic is open and visible on your main screen and the program is visible on your second monitor.

For troubleshooting, please reach out to Joshua Buss for help.
